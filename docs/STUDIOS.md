# Киностудии

Селфи-поиск студию не закрывает. Здесь отдельный контур.

В карточке: тип площадки, число павильонов, площадь, мощность, LED/VP, потолок по группе, вилка дня, кто выдаёт пермит, call sheet и точка для Unreal.

API: GET /api/studios, POST /api/studios/search, GET /api/studios/{id}/callsheet, GET /api/studios/{id}/unreal

Цифры дня — ориентир для препродакшна, не оферта.
